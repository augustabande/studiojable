# StudioJable (Next.js)

**StudioJable** is my latest personal project, a modern **Next.js 13** web application designed to experiment with dynamic content, animations, and image galleries.  
It combines performance, accessibility, and clean architecture, making it a solid example of my approach to building **scalable and user-friendly applications**.

---

## ✨ Features
- Built with **Next.js 13.4** and **React 18**  
- Static site generation (SSG) and server-side rendering (SSR)  
- Content management with **Markdown** via `gray-matter`, `remark`, and `remark-html`  
- Smooth animations powered by **GSAP**  
- Image galleries with **PhotoSwipe** + `react-photoswipe-gallery`  
- Sliders and carousels using **Swiper 9**  
- Form handling with **Formik**  
- Video support via **React Modal Video**  
- SEO optimization with **next-sitemap**  
- Responsive styling with **Sass** and modern CSS  

---

## 🛠️ Tech Stack

- **Framework:** Next.js 13.4.3  
- **Core:** React 18.2.0, React DOM 18.2.0  
- **Animations:** GSAP 3.11.5  
- **Forms:** Formik 2.4.2  
- **Content Processing:** Gray-Matter 4.0.3, Remark 14.0.3, Remark-HTML 15.0.2  
- **Images & Media:** PhotoSwipe 5.3.7, React PhotoSwipe Gallery 2.2.7, React Modal Video 2.0.0  
- **UI & Styling:** Swiper 9.0.0, Sass 1.49.7  
- **Date Utils:** date-fns 2.30.0  
- **SEO:** next-sitemap 4.2.3

## ⚡ Quick Start

1. Clone the repo  
   ```bash
   git clone https://github.com/augustabande/studiojable.git
   cd studiojable

2. Install dependencies
     ```bash
    yarn install

3. Start development server
     ```bash
    yarn dev

4. Build for production
     ```bash
    yarn build
    yarn start
